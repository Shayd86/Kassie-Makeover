# Kassie Makeover v0.3.0 — C# / WPF rewrite

This is the clean C# rewrite of Kassie Makeover. It intentionally does **not** carry forward the old web/Edge shell or the C++/Go native prototypes.

## Architecture

- C# / .NET 8
- WPF desktop UI
- Windows x64
- self-contained publish target (user does not install .NET manually)
- OpenCvSharp camera layer with DirectShow -> Media Foundation -> automatic backend fallback
- no browser, localhost server, Node, Python, Go, PowerShell, or terminal required for normal use
- clean camera release on window close
- single-instance guard

## Paths

Installed application:

`F:\Kassie Makeover\Kassie-Makeover.exe`

Persistent/changeable data:

`D:\Kassie\Makeover\`

including models, runtimes, caches, outputs, exports, wardrobe, config, temp files, and logs.

## Branding

The approved Kassie Makeover artwork is embedded as an application resource. It is not regenerated by the app.

## Current v0.3.0 scope

This rewrite deliberately gets the foundation right first:

- camera discovery
- live native preview
- DirectShow / Media Foundation fallback
- camera switching
- mirror toggle
- snapshots to `D:\Kassie\Makeover\outputs`
- deterministic camera shutdown/release
- native C# window and navigation shell
- Makeup / Hair / Outfit / Looks / Wardrobe sections prepared for the next implementation stages

Outfit remains planned in **both live webcam and high-quality still-image modes**.

## Building

The repository includes `.github/workflows/build-windows.yml`. A Windows GitHub Actions runner restores NuGet packages, publishes a self-contained Windows x64 `Kassie-Makeover.exe`, creates the Hub update ZIP with the SHA-256 of the actual EXE, and builds an Inno Setup installer.

The normal Hub package is generated as:

`Kassie-Makeover-v0.3.0.zip`

containing only:

- `Kassie-Makeover.exe`
- `kassie-release.json`

The standalone installer is generated as:

`Kassie-Makeover-Setup-v0.3.0.exe`

and installs to `F:\Kassie Makeover`.
